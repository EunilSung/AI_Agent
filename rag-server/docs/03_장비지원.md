# 샘플컴퍼니 개발 장비 지원 제도

## 기본 지급 장비
개발 직군은 입사 시 MacBook Pro 1대와 27인치 모니터 1대를 지급받는다. 노트북 교체 주기는 4년이다.

## 테스트 기기
iOS/Android 테스트 기기는 장비 관리 담당자에게 대여 신청서를 내고 빌린다. 대여 기간은 최대 2주이며, 연장은 1회 가능하다.

## 자기계발 장비 지원
업무 관련 장비나 도서 구입비를 연 50만 원까지 지원한다. 구입 후 30일 이내에 영수증을 첨부해 그룹웨어 [경비 > 자기계발비]로 청구한다.

## AI 도구
사내 AI 도구 사용 시 고객사 코드와 개인정보는 외부 클라우드 AI에 입력하지 않는다. 이런 자료는 사내망의 로컬 LLM 서버만 사용한다.
