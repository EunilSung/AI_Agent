# 샘플컴퍼니 재택근무 가이드

## 대상과 횟수
수습 기간(3개월)이 끝난 정규직 직원은 주 2회까지 재택근무를 할 수 있다.
월요일은 전사 회의가 있으므로 재택근무를 할 수 없다.

## 신청
재택근무는 전날 오후 6시까지 그룹웨어의 [근태 > 재택근무 신청]에서 신청하고 팀장 승인을 받는다.

## 근무 수칙
재택근무 중에는 코어타임(오전 10시~오후 4시) 동안 메신저 상태를 "근무 중"으로 유지한다.
고객사 소스 코드와 개인정보가 포함된 자료는 반드시 회사 지급 노트북과 사내 VPN으로만 접근한다.
공용 와이파이(카페 등)에서는 고객사 시스템에 접속하지 않는다.
